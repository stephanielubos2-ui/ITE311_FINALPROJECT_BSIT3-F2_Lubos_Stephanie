# SerbisYou

**Student Name:** Lubos, Stephanie
**Course and Section:**  - <BSIT III-F2>

## Project Description
SerbisYou is a CMS-based campus skill marketplace where students can offer and avail of creative, event support, and digital services from fellow students. It allows users to post services, browse listings, and manage their profiles in one platform.

## Technologies Used
- HTML, CSS, JavaScript
- PHP / CodeIgniter 4
- MySQL
- Git and GitHub
